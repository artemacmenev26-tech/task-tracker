# Task Tracker

Учебное веб-приложение для управления повседневными задачами.

## Возможности

- добавление задачи кнопкой или клавишей Enter;
- отметка задачи как выполненной;
- удаление задачи;
- сохранение списка и состояния задач в `localStorage`;
- адаптивный интерфейс для компьютеров и смартфонов.

## Технологии

- HTML5;
- CSS3;
- JavaScript;
- DOM API;
- JSON и `localStorage`.

## Запуск

Скачайте проект и откройте файл `index.html` в браузере. Установка зависимостей не требуется.

## Структура проекта

- `index.html` — разметка приложения;
- `style.css` — оформление и адаптивность;
- `script.js` — логика работы с задачами и браузерным хранилищем.
